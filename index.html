Sistemas de notas

O Sistema de Notas Acadêmicas é uma aplicação desenvolvida em Java que registra o nome e o RA do aluno, recebe as notas de Português, Matemática e Ciências e calcula automaticamente a média final.

O sistema verifica se o aluno foi aprovado com base em duas condições: possuir média igual ou superior a 6 e não ter nota inferior a 3 em nenhuma disciplina. Ao final, apresenta um resumo com os dados do aluno, suas notas, a média calculada e a situação acadêmica.

Tecnologias

  • Java: linguagem utilizada no desenvolvimento.
  • Scanner: classe usada para receber dados digitados pelo usuário.
  • Variáveis e tipos de dados: utilização de String, double, int e boolean.
  • Entrada e saída de dados: uso de Scanner e System.out.println().
  • Operadores aritméticos: cálculo da média das notas.
  • Operadores relacionais e lógicos: verificação dos critérios de aprovação com >= e &&.
  • Conversão de tipos (casting): transformação da média de double para int.
  • Lógica de programação: processamento das notas e definição da situação do aluno.

Dias da Semana

O Identificador de Dia da Semana é uma aplicação desenvolvida em Java que solicita ao usuário um número entre 1 e 7 e apresenta o dia da semana correspondente.

O sistema utiliza uma estrutura de decisão para relacionar cada número a um dia, considerando 1 como domingo e 7 como sábado. Caso o usuário digite um número fora desse intervalo, uma mensagem informa que o valor é inválido.

Tecnologias

  • Java: linguagem utilizada para desenvolver a aplicação.
  • Scanner: classe responsável por receber o número digitado.
  • Variáveis e tipos de dados: armazenamento do número em uma variável do tipo int.
  • Estrutura switch-case: seleção do dia correspondente ao número.
  • Comando break: encerra cada caso após sua execução.
  • Cláusula default: trata números fora do intervalo permitido.
  • Entrada e saída de dados: uso de Scanner e System.out.println().
  • Validação de dados: identificação de valores inválidos.

Classificador de idade

O Classificador de Faixa Etária é uma aplicação desenvolvida em Java que solicita o nome e a idade do usuário e, com base nas informações fornecidas, classifica sua faixa etária.

As classificações utilizadas são:
Criança: menos de 12 anos;
Adolescente: entre 12 e 17 anos;
Adulto: entre 18 e 59 anos;
Idoso: 60 anos ou mais.
Ao final, o sistema apresenta o nome da pessoa e sua respectiva classificação.

Tecnologias

  • Java: linguagem utilizada no desenvolvimento.
  • Scanner: classe usada para receber os dados digitados.
  • Variáveis e tipos de dados: uso de String para o nome e int para a idade.
  • Estruturas condicionais: utilização de if, else if e else.
  • Operadores relacionais: comparação da idade por meio do operador >=.
  • Entrada e saída de dados: uso de Scanner e System.out.println().
  • Lógica de programação: classificação do usuário conforme sua faixa etária.
  • Tratamento do buffer: uso de scanner.nextLine() após nextInt().

Advinhe o numero

O Jogo de Adivinhação é uma aplicação desenvolvida em Java que gera aleatoriamente um número secreto entre 1 e 10 e desafia o usuário a descobri-lo.

Enquanto o número digitado estiver incorreto, o sistema informa se a tentativa foi maior ou menor que o número secreto e solicita uma nova resposta. O jogo termina quando o usuário acerta, exibindo uma mensagem de parabéns.

Tecnologias

  • Java: linguagem utilizada no desenvolvimento.
  • Scanner: classe usada para receber as tentativas do usuário.
  • Math.random(): método utilizado para gerar o número aleatório.
  • Conversão de tipos: casting de double para int.
  • Laço de repetição while: mantém o jogo em execução enquanto o usuário não acertar.
  • Estrutura condicional if/else: verifica se a tentativa foi alta ou baixa.
  • Operadores relacionais: utilização de != e >.
  • Variáveis: armazenamento do número secreto e da tentativa.
  • Entrada e saída de dados: uso de Scanner e System.out.println().
  • Lógica de programação: comparação das tentativas com o número secreto.
